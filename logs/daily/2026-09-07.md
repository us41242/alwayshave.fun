## Learning
When a self-check fails, recompute the specific case by hand before
touching the code: the literature value is for the generic case and the
test hand had a suited fifth card. A wrong test would have "fixed" a
correct engine.
Cloudflare 1010 is per-user-agent; it will bite any script with a
default library UA, and it looks like a site outage if you don't check
the response body.
